# README style contract

Use concrete implementation nouns and measured behavior. Avoid unverified superlatives.

Prefer:

- `FastAPI service with WebSocket job events`
- `renderer interface for Manim`
- `prototype path`
- `measured on <documented configuration>`

Avoid unless directly established:

- `perfect`
- `revolutionary`
- `production-ready`
- `enterprise-grade`
- `fully autonomous`
- `guaranteed`

If a capability is planned or scaffolded, say so directly.
