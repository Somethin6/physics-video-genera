# Scope

Physics Foundry is a prototype for local-first scientific-media generation workflows. The repository's near-term scope is deliberately narrow: orchestrate a bounded physics prompt into structured planning data, generated Manim source, sandboxed rendering, persisted artifacts, and measurable QA.

Out of scope for current portfolio claims:

- guaranteed autonomous correctness;
- production-grade multi-tenant isolation;
- verified Blender/Taichi parity with the Manim path;
- guaranteed audio synchronization quality;
- universal physics-topic coverage.
