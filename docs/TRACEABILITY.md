# Claim traceability

For a portfolio-facing claim, record:

| Field | Value |
| --- | --- |
| Claim | exact public wording |
| Code | file/function implementing it |
| Test | test/reference command |
| Artifact | retained result if applicable |
| Environment | relevant dependency versions/hardware |
| Limitation | boundary of the claim |

This template is intended for the small number of claims that remain on the final concise README after the audit branch is consolidated.
